Batch modernization: SSIS to .NET Core

A set of daily batch jobs moved off SSIS onto .NET Core, and the whole cycle now runs in a third of the time.

Problem

A set of daily SSIS jobs took 1.5 hours to run and was hard to maintain.

Approach

I led a team of three to four engineers that migrated about seven jobs to .NET Core, applying the Clean Architecture patterns already proven in existing applications.

Result

Total batch runtime fell from 1.5 hours to 30 minutes.

Before
1.5 h
After

My role

I led delivery: planning the migration, coordinating the team and getting the jobs into production. The architecture patterns came from existing applications; my job was applying them well.
